# Atlas 商用密码应用安全性评估证据矩阵

> **当前角色**：密码与隐私安全负责人
> **本章产出**：SM2/SM3/SM4 落地点、密钥生命周期与密评证据映射
> **依赖的上游产出**：ADR-014、ADR-020、ADR-022、ADR-024、ADR-026

## 1. 声明边界

附件提出的 SM2/SM3/SM4 强制范围以及 MAC 绑定要求需在项目所在地适用性评估后确认，统一标记 `[待验证]`。本设计默认按“核心诊疗数据链路和审计证据均使用国密能力”实现，并保留经过审批的互操作适配层。

## 2. 密码应用映射

| 环节 | 密码机制 | 密钥对象 | 保护目标 | 验证证据 |
|---|---|---|---|---|
| 服务间传输 | SM2 协商、SM4 加密（认证模式候选为 SM4-GCM，`[待验证]`）、SM3 完整性 | 节点证书与传输密钥 | 机密性、完整性、节点身份 | 抓包、证书链、负向测试、密码产品互操作报告 |
| 外部接入 | SM2/SM4；TLS 互操作代理 | CA/RA 签发证书 | 用户与设备身份 | CA 审计、证书吊销测试 |
| 业务存储 | SM4 字段级或表空间加密 | 租户数据密钥 | 磁盘/备份介质外泄防护 | 密文检索、原值比对 |
| 审计事件 | SM3 哈希链 + SM2 签名 | 分区签名密钥 | 顺序性与不可否认性 | 篡改注入、第三方验签 |
| 备份 | SM4 备份加密，SM3 清单 | 备份密钥 | 备份介质安全 | 恢复演练、清单验证 |
| 配置与密钥 | Vault/KMS + SM2 信封加密 | 根密钥/KEK/DEK | 密钥保密与轮转 | 轮转记录、访问审计 |

`SM4-GCM` 仅作为待评估候选模式，不构成已选定的合规基线；必须以适用标准、获证密码产品接口和密评机构书面意见确定最终模式、nonce/tag 长度与失败策略。

## 3. 密钥层级

```text
离线根密钥
  └─ 院区主密钥 KEK（HSM/Vault）
       ├─ 业务数据 DEK
       ├─ 审计签名密钥
       ├─ 节点传输密钥
       └─ 备份 DEK
```

规则：

1. 根密钥不进入配置文件、镜像、日志、环境变量或数据库。
2. DEK 按用途、院区、数据域和版本隔离；密文携带 key version。
3. 轮转采用“新密钥写新数据 + 后台重加密旧数据”双轨；旧密钥仅解密。
4. 审计签名密钥按时间窗和院区隔离，暴露时只影响有限窗口。
5. 紧急吊销必须同时触发签核写回停用、节点隔离和事件响应。

## 4. 时间戳与验签

医疗审计依赖可信时间。服务节点使用 NTP/PTP；审计分区维护单调序列与规范化时间戳。第三方验证器输入原始事件、链头、签名和证书链，输出：

```json
{
  "valid": true,
  "first_invalid_sequence": null,
  "chain_length": 1000,
  "certificate_status": "valid",
  "algorithm": "SM3/SM2",
  "verified_at": "RFC3339 timestamp"
}
```

任何序列缺失、乱序、哈希或签名不匹配都必须报告精确位置，不允许“部分有效”后继续接受全链通过。

## 5. 密评交付清单

| 类别 | 文档/证据 | 验收要求 |
|---|---|---|
| 制度 | 密钥管理制度、运维规程、应急流程 | 版本受控、审批完整 |
| 资产 | 密码应用资产清单、网络拓扑、数据流 | 与生产实例一致 |
| 密码产品 | 产品型号、证书、配置基线 | `[待验证]` 适用资质由合规负责人核验 |
| 密钥 | 生成、分发、存储、轮转、销毁记录 | 无明文密钥、无未审批共享 |
| 算法 | SM2/SM3/SM4 配置与协商日志 | 禁用不合规降级 |
| 实现 | 协议、接口、异常处理、代码审计 | 负向测试通过 |
| 运行 | 密钥调用、轮转、吊销、验签记录 | 抽样可追溯 |
| 应急 | 泄露处置、吊销、回滚演练 | 限时完成并复盘 |
| 第三方 | 独立验证和测评报告 | 阻断项清零 |

## 6. 密码测试门禁

- SM2 证书链、过期、吊销、错误用途和重复主题测试全部通过。
- SM3 任意字段、顺序、链头或时间戳篡改均被检测。
- SM4 密文、nonce、tag、密钥版本或 AAD 篡改均失败且不泄露明文。
- 算法降级、未知套件、错误密钥和重复随机数被拒绝。
- 密钥轮转期间旧数据可读，新数据只使用新版本，审计记录完整。
- 性能基准在目标硬件上实测；未实测的容量数字标 `[待验证]`。

## 7. 责任与复核

密码负责人维护算法和密钥基线；平台负责人实现接口；独立测试人员执行负向验证；合规负责人核验法规和测评机构要求。任何例外必须记录风险、补偿控制、到期日与批准人。
