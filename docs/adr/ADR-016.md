# ADR-016：模型版本管理、灰度、回滚与强制停用阈值

## 背景

模型、提示词、规则、Schema 和依赖任何一项变化都可能改变临床建议。只按镜像标签发布无法回答“哪组数据产生了哪条建议”，也无法在漂移或不良反应时证明影响范围。强制停用不能依赖模型团队自觉：必须由独立控制面在证据条件成立时收回流量令牌，未审查建议同步失效。灰度只改变建议暴露范围，不改变 ADR-001 的人工签核红线。

## 选项对比

| 方案 | 复现 | 灰度 | 紧急停用 | 结论 |
|---|---|---|---|---|
| A：容器 tag + 手工回滚 | 弱 | 弱 | 依赖人工 | 拒绝 |
| B：注册表 + 百分流量，无硬停机 | 强 | 有 | 模型团队可忽略 | 拒绝 |
| C：内容寻址注册 + 签核门禁 + 分阶段灰度 + 独立硬停机 | 强 | 可审计 | 自动阻断 | **采用** |

## 决策

### 1. 模型注册与不可变身份

注册表记录：模型/规则/提示/Schema/术语/评测集版本、训练/微调数据摘要、基础模型许可证、训练与知识截止时间、代码/容器/依赖摘要、SBOM、量化与安全配置、适用任务/人群、禁用场景、校准器、阈值、评测报告、批准人和生效期。制品在院内验证签名与摘要后才能取得部署租约。

发布 ID 对规范清单计算内容摘要；相同内容可复现，不同内容必须新 ID。注册表只追加，不覆盖；停用是新状态事件。每次建议记录完整 `model_release_id` 及依赖摘要，可沿 lineage 找到证据和撤销范围。

### 2. 分阶段灰度

| 阶段 | 流量/用户 | 允许动作 | 晋级门禁 |
|---|---|---|---|
| S0 离线评测 | 0 临床流量 | 不生成可见建议 | 临床、安全、合规双签；硬规则/证据链测试通过 |
| S1 影子 | 0 展示、0 签核 | 与生产结果对照，不向医生呈现 | 事实/证据一致、时延容量、偏差报告 |
| S2 内部金丝雀 | 授权测试账号，固定小比例 | 仅签核演练，不回写临床 | P0/P1 缺陷为零，审计链完整 |
| S3 受控灰度 | 按院区/任务/人群分桶 | 人工签核 | 约定观察窗内安全与性能门禁通过 |
| S4 扩大 | 分阶段提高比例 | 人工签核 | 每次扩大独立审批和可逆操作 |
| S5 稳定 | 目标流量 | 人工签核 | 持续监测和周期复评 |

分桶以稳定、不可识别患者键在院内计算，灰度期间同一患者/临床上下文固定版本；不得把患者标识发到控制面。试验需预设最小样本、观察窗、统计方法和停止条件。并发临床试验需独立治理。具体比例与观察窗为 `[待验证]`，由功效分析和临床风险评审确定，不得从生产后数据反推。

### 3. 独立停用控制面

模型运行面只持有短期部署租约；安全/评测服务监测事件并调用控制面吊销租约。模型所有者不能删除指标、修改硬阈值或重置计数。控制面与模型面分离部署、职责和凭据；停用写入 ADR-014 审计。控制面不可用时，所有新灰度/扩大被阻断；稳定版本按既定保守策略运行并告警。

触发立即停用候选/现网版本的条件（不可被模型所有者覆盖）：

1. 任何未经签核建议进入临床写路径，或审计/证据链缺失；
2. 任一经验证的“哨兵严重安全事件”归因于该版本：错患者建议、致命禁忌推荐、超剂量建议或不可逆临床错误；
3. 发布制品/签名/SBOM 与注册摘要不一致；
4. 校准或适用范围失效、关键输入分布越界且未安全降级；
5. 达到经验证的漂移/质量/不良反应统计阈值。

第 1、3 项是零容忍。第 2 项“可信报告→临时冻结、临床归因→维持或解除”，避免单次非归因事件被忽视；临时冻结期间该版本不再生成新建议。哨兵定义、归因流程和阈值必须由临床安全委员会批准。

### 4. 初始强制阈值

以下为发布前必须量化的安全护栏，其候选起点如下，均为 `[待验证]`，实测与临床批准前不得作为生产事实：

| 信号 | 候选硬触发 | 附加条件 |
|---|---|---|
| 哨兵严重安全事件 | 1 个经初筛可信事件 | 立即临时冻结；1 个经正式归因事件维持停用 |
| Schema/证据/术语硬错误率 | 15 分钟窗口 `>0.5%` 且样本 `≥100` | 自动停用；0 个关键字段缺失事件/正常突发 |
| 输入分布漂移 | PSI `>0.25` 持续 30 分钟 | 结合关键子群/漂移确认；安全护栏更严格时不等待确认 |
| 校准 ECE | 超出批准上限 `0.05` 的 1.5 倍 | 有效样本达到统计最小量 |
| 假阳性率 | 滚动 24 小时 `>5%` 或超过批准对照上限 | 分母可计算、低样本不按低率误放行 |
| 关键提醒召回 | 滚动证据窗 `<95%` | 排除状态前须满足预设统计置信要求 |
| 重复/错关联 | 任一错患者事件或重复写入 | 立即停用并启动安全事件 |

平台可收紧阈值；降低硬阈值必须走独立临床/安全/合规批准并重跑灰度。采样置信、漂移窗口、PSI 分箱和不同时效变化可能造成误报，候选值要通过历史影子数据评估。

### 5. 停用动作

停用不是删模型：吊销租约、停止新生成、标记 `REVOKED`、撤回缓存、阻断灰度控制面、列出受影响建议/审核任务，并发送通知。未签核建议全部转为 `REVOKED`，不得切换版本后自动继承签核；需要重评。已签核但未提交的证书按 ADR-001 失效；已提交临床事实只能追加纠正/冲正流程。回滚候选版本也必须满足注册、评测和当前阈值。

### 6. 漂移与对抗输入

同时监测输入特征/术语/缺失率、输出结构、证据可用性、队列/审核行为、院区和人群分群、延迟及人工推翻率。仅监测总体均值会掩盖稀有高危人群；每个关键分群设最小样本。数据质量服务不可用或样本不足时结果为 `UNKNOWN` 并阻止扩大/恢复，不能视为“无漂移”。

## 可复算推导

生产建议量 `A=10,000,000/月`、平均 `3.9/秒` 只说明均值，不足以设停用窗。若候选质量窗口为 15 分钟，均匀到达的期望样本约：

`n_window = 3.9 × 900 = 3,510` 条

若实际 15 分钟样本仅 100，则质量率估计误差较大，必须用区间而非把 0/100 当作 0 风险。峰值 200/秒时同窗样本可达 `200×900=180,000`，分布与告警风暴评估为 `[待验证]`。

二项比例 Wilson 95% 上界近似写为（0 成功时）：

`U95 ≤ 3/n`

质量错误候选阈值 0.5% 至少需 `n>3/0.005=600` 才有机会在零错误时使上界低于 0.5%；设置 `n≥100` 只够触发计算，不足以证明 0.5% 达标。若观测 1/600，Wilson 上界会明显高于 3/600，精确区间由统计库计算并附分群。样本独立性假设和实际统计功效为 `[待验证]`，验证方法：以历史影子分布模拟误报/漏报，进行预注册统计功效分析。

漂移稳定指数按分箱定义：

`PSI = Σ (actual_p_i - baseline_p_i) × ln(actual_p_i / baseline_p_i)`

基线百分比加平滑/空箱处理，窗口、切点和候选 0.25 需历史回放。任何模型/规则/术语版本变化建立新基线，不能把计划变化掩盖成漂移；反之未经批准的变化不能自动刷新基线。

## 安全后果

- 强制停用优先患者安全，但保守阈值可能造成可用性下降和临床中断；必须有经签核的安全回退版本。
- 分阶段灰度减少爆炸半径，不能把任何阶段变成自动写临床。
- 独立控制面防止模型团队自评自批，但控制面自身成为高价值攻击目标，需要双签、凭据隔离和演练。
- 单一临床哨兵事件可能证据不足，临时冻结与正式归因分离既不忽视也不永久误停。
- 版本谱系与撤销提高可追责性，代价是缓存、索引和任务状态同步复杂度。

## 回滚方案

1. 候选未上线：撤销发布租约，回到上一稳定版本或停止建议生成；候选制品只读保留供调查。
2. 灰度中：立即把灰度桶路由回上一安全版本，吊销未完成证明，重算受影响任务。
3. 稳定版触发：进入降级模式，只保留经批准的确定性安全规则和人工流程；不得用未经停用流程的旧模型“临时顶替”。
4. 若无可用安全版本，停止新建议并显示临床服务替代路径；急诊/抢救按 ADR-002 人工流程处置。
5. 回滚验收包括租约吊销即时生效、缓存/未签任务撤销、影响清单完整、审计无缺口、前一版本重新经过健康检查且没有跨版本继承签核。
