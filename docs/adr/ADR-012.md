# ADR-012：去标识化方案与再识别风险评估

## 背景

Atlas 的原始诊疗数据原则上 100% 留在院内；确需用于评测、研发或跨环境的脱敏数据必须通过受控管线。单纯删除姓名不能消除年龄、罕见病、就诊日期、机构等组合造成的再识别风险。去标识化也不等于匿名化：若可借助外部数据合理重识别患者，仍应按个人信息保护要求管理。不同目标的等价类大小、时间粒度和地理精度不同，不能用一个全局 k 值。

## 选项对比

| 方案 | 隐私强度 | 临床分析可用性 | 验证成本 | 结论 |
|---|---|---|---|---|
| A：仅删除姓名/证件等直接标识 | 低 | 高 | 低 | 拒绝 |
| B：全量合成数据 | 较高 | 合成偏差需评估 | 高 | 适合测试，不替代真实分布评测 |
| C：风险驱动 k-匿名 + 抑制 + 泛化 + 再识别攻击测试 | 可量化 | 按用途平衡 | 中高 | **采用** |

## 决策

### 1. 用途画像与准标识符

每个释放目的先建立 `DeidentificationPurpose`：允许字段、必需分析属性、攻击者辅助数据、地区、时期、发布环境和保留期。默认准标识符至少覆盖：年龄/出生日期、性别、精确日期、地区/机构、稀有诊断与操作组合、住院/就诊序列、职业和设备标识。不同用途不共享同一脱敏参数。

拟采用的具体标准、法定匿名化判断和允许的稀有疾病处理为 `[待验证]`。验证方法：法务/隐私负责人逐条映射适用法规和合同，由伦理与数据治理委员会批准用途画像；技术团队以该画像生成字段允许表。

### 2. k-匿名处理

对每个等价类 `C`，每个准标识符组合的频数满足：

`∀C: |C| ≥ k`

实现流水线：

1. 链接同一数据域的患者/事件，确定患者级等价类。
2. 通过泛化层级降低精度：日期从日→月→年，地理从门牌→街道→区→省，年龄分箱并处理边界开放区间。
3. 排序后以滑动窗口最小化数据效用损失，形成泛化层级。
4. 对 `<k` 的稀有类执行抑制、泛化到更高层级或排除；不得只加噪后保留唯一组合。
5. 验证最终输出每个等价类实际大小，不以输入设计值代替。

初始 `k` 不得在未评估时写死。设候选 `k∈{5,10,20}`，按每个用途比较覆盖率、记录保留率、时间分析可用性和攻击成功率；最终值由隐私、临床和伦理共同批准。候选值与适用性为 `[待验证]`。验证方法是对每个用途做参数扫描和重识别测试，并报告最坏分群，不只给总体平均。

### 3. 泛化与抑制规则

| 字段 | 泛化 | 抑制/保留规则 |
|---|---|---|
| 出生日期 | 按用途转年龄区间 | 极高龄边界合并；不输出精确生日 |
| 事件日期 | 日→周/月或相对日 | 保留临床所需时间间隔时优先一致日期偏移 |
| 地理 | 层级表 | 稀有地区合并；禁止输出可定位小样本机构组合 |
| 诊断/操作 | 保留必需概念或父级组 | 极罕见组合按隐私优先抑制 |
| 医师/设备 | 泛化为科室/设备类别 | 若会重识别患者则拒绝发布 |
| 稀有值 | 统一缺失类或受控桶 | 禁止逐行唯一假名化 |

日期偏移必须在同一患者的获准分析域内一致，并记录偏移算法；偏移后的时间差可保留，但精确日历事件可能泄露，统一由数据治理批准。自由文本、病理描述和 DICOM 烧录文字需单独的 PHI 检测/人工抽样，不能因结构化字段通过 k 匿名就自动放行。

### 4. 再识别风险评估

| 攻击 | 评估 | 阻断条件 |
|---|---|---|
| 单一属性推断 | 某稀有属性/准标识符可唯一匹配 | 唯一匹配即失败 |
| 链接攻击 | 用公开/授权辅助数据匹配合并类 | 超过批准再识别率即失败 |
| 成员推断 | 判断某患者是否在数据集中 | 超过任务批准风险即失败 |
| 属性披露 | 从等价类推断敏感属性 | 超出用途允许范围即失败 |
| 稀有类别/小样本 | 高危人群被单独识别 | 不满足 k 或专门保护规则即失败 |
| 自由文本/图像残留 | 直接或间接标识符残留 | 任何确证标识符残留即失败 |

附件给出的再识别率目标为 `<0.1%`。若评估 `M` 次独立匹配攻击，其中 `S` 次成功，单侧 95% 上界可近似：

`U95 ≈ 3 / M`（零成功时）

要使 `U95<0.001`，需 `M>3,000`；若恰好 `M=3,001` 且零成功，则 `3/3,001≈0.0009997<0.001`。攻击独立性、辅助数据和置信水平均需按真实场景确认，为 `[待验证]`。验证方法包括专家、机构匹配、稀有属性、全量辅助数据等攻击，并报告按院区/人群分层的置信区间。

### 5. 发布与访问

原始、候选脱敏、已批准脱敏数据分库存储，权限和密钥隔离；脱敏输出有清单、参数版本、风险报告和审批。外部发布使用逐次审批令牌、加密、到期和下载审计。脱敏管线只追加版本；修正生成新版本。真实数据不得进入 CI 或压测，测试用合成数据仍要通过生成器隐私扫描。

## 可复算推导

设原始 `N` 条患者记录，泛化后因稀有类被抑制/排除 `R` 条：

`record_retention = (N - R) / N`

若 `N=100,000、R=3,000`，保留率 `=97,000/100,000=0.97=97%`。这不代表安全达标；还必须逐等价类验证 k、执行攻击测试并检查文本/图像残留。任何效用指标不得优先于隐私硬门禁。

k 匿名的最坏类至少为 k。若在 100,000 个等价类中 2,000 个大小为 5、98,000 个大小至少为 20，则最小类比例 `=2,000/100,000=2%`，表示不能只报告平均类大小；这 2% 必须满足 k 与攻击风险。样例参数为算例，真实分布为 `[待验证]`，通过用途画像后的等价类统计确认。

## 安全后果

- k-匿名提供最低结构化保护，但可能被辅助数据、自由文本和稀有类别突破，因此必须组合攻击测试。
- 一致日期偏移保持纵向分析，却可能泄露节假日/精确流程，需按用途限制。
- 过度泛化可能降低临床评测有效性；用途画像和效用报告使取舍显式，但不得用效用突破隐私门禁。
- 脱敏数据仍可能被重新识别，不应在未经评审的情况下作为自由开放数据。

## 回滚方案

1. 新泛化/抑制算法发布失败时固定到上一批准参数；新输出不自动替换旧集。
2. 发现唯一类或残留标识符时立即撤销发布令牌、隔离文件、通知隐私负责人并评估影响。
3. 参数过严导致研究不可行时，新增用途画像并重新走风险/伦理审批，不能临时降低 k。
4. 回滚验收覆盖等价类大小、唯一匹配、文本/图像残留、攻击置信区间、版本一致性和访问审计。
