## 背景

模型或规则评分并不天然代表真实事件概率。若直接按 0.8 与 0.6 设阈值，分布变化后会造成大量假阳性或漏检。附件要求关键提醒召回不低于 95%、假阳性率不高于 5%、ECE 不高于 0.05，因此 Atlas 必须区分原始分数、校准概率、阈值动作和临床签核。即使进入“拦截”层，也只表示阻止不可靠建议或强制人工处理，不表示自动形成诊断、处方或医嘱。

## 选项对比

| 方案 | 数据需求 | 非线性表达 | 漂移治理 | 结论 |
|---|---|---|---|---|
| A：使用模型原始 softmax/自报置信度 | 低 | 隐含 | 弱 | 拒绝 |
| B：Platt scaling | 低至中 | 简单单调 | 稳定、易审计 | 首选基线 |
| C：Isotonic regression | 较高 | 强单调 | 易过拟合 | 小样本不足时受限采用 |

## 决策

### 1. 校准对象与隔离

每个可输出风险分数的独立任务单独校准，例如“某药物规则命中”“某检验风险判断”“文书完整性评分”；不能把不同临床任务混成一个概率。校准标签必须由盲法人工标注或经批准的确定性结局定义产生。训练、校准、阈值选择和最终验收集相互隔离；阈值不得在同一测试集上反复优化后报告成绩。

数据按时间、院区和关键人群分层。训练和阈值选择数据可来自经批准的去标识化/合成数据，最终独立验收集不得参与阈值调参。院区、设备、疾病谱变化时重新评估；校准器、适用分群、训练截止时间和证据摘要必须进入模型注册表。

### 2. Platt 校准

将原始分数 `s` 经逻辑函数转换为概率：

`P(y=1|s) = 1 / (1 + exp(A s + B))`

通过带正则的二元逻辑回归拟合 `A/B`。Platt 适合样本较少或关系近似单调的情况；如果验证残差结构显示明显非线性，再比较 Isotonic，而不是默认选择更复杂方法。

### 3. Isotonic 校准

Isotonic 在保持单调的同时拟合 `P(y=1|s)`，使用池相邻违规算法 PAVA。该方法可能对噪声过拟合；采用条件包括：各校准分箱有足够样本、采用交叉拟合或独立集验证、时间外推表现优于 Platt，并发布阶梯函数/分箱表。任何超出训练分数范围的外推均返回 `UNKNOWN` 或 `OUT_OF_DISTRIBUTION`，不得插值成高置信。

### 4. 校准指标

| 指标 | 公式 | 发布含义 |
|---|---|---|
| ECE | `Σ(B_i/N)|acc_i-conf_i|` | 越小越好，但不能单独代表性能 |
| MCE | `max_i |acc_i-conf_i|` | 捕捉最差分箱偏差 |
| Brier | `Σ(p_i-y_i)^2/N` | 概率均方误差 |
| 校准曲线 | 各分箱事件率对预测概率 | 必须分时间、院区、人群查看 |
| AUROC/AUPRC | 排序能力 | 与实际决策阈值分开评估 |
| 灵敏度/假阳性率 | `TP/(TP+FN)`、`FP/(FP+TN)` | 对应临床任务门禁 |

以 ECE 加权分箱报告，并附每个分箱的 Wilson 或 bootstrap 置信区间。定义、样本量和分箱策略必须公开，禁止只给单个总体数字。

### 5. 阈值动作

| 层级/门禁 | 条件（示意，发布值见注册表） | 系统动作 | 临床动作 |
|---|---|---|---|
| 质量门禁 | `p < T_quality`、证据不完整、规则不确定或 OOD | 在风险分层前阻止生成/发布建议或隔离 | 转人工/补证据，不自动执行 |
| 提示 | `p ≥ T_quality` 且 `p < T_warn` | 展示证据，可正常签核 | 人工决定 |
| 警示 | `T_warn ≤ p < T_block` 或关键高风险规则命中 | 突出证据、确认已理解，不能跳过签核 | 必须人工签核 |
| 高风险/拦截动作 | `p ≥ T_block` 或确定性硬规则命中 | 强制升级/阻止普通放行；不自动执行 | 由临床人员处置 |

示例阈值仅说明分层结构，不得作为生产值，且质量门禁与风险分层是正交门禁：`T_quality=0.05、T_warn=0.20、T_block=0.70` 时，0.01 先被质量门禁拦截，0.10 进入提示，0.60 进入警示，0.90 进入高风险动作；任何区间都不自动入病历。阈值由成本函数选择：

`J(T) = C_FN·FN(T) + C_FP·FP(T) + C_delay·Delayed(T) + C_human·Human(T)`

并满足硬约束 `Recall≥95%`、`FPR≤5%`、临床禁用子集零漏检。`C_*` 和各阈值均为 `[待验证]`，由临床风险工作坊、决策曲线分析和独立验收集确定。

## 可复算推导

若预计假阳性率 `p≈0.05`，希望 95% 正态近似的半宽 `d=0.003`，所需独立阴性样本量近似：

`n = z²·p(1-p)/d² = 1.96² × 0.05 × 0.95 / 0.003² ≈ 20,275.1`

向上取整为 20,276 个独立阴性样本。实际还应按院区、人群和任务分层并为数据相关修正扩大样本量；独立性与效应假设为 `[待验证]`。验证方法是计算样本功效/精度，报告置信区间和有效样本数，不能把重复样本当作独立样本。

ECE 的分箱必须固定，例如 10 个等频箱。对第 `i` 箱有 `n_i` 个样本：

`ECE = Σ(n_i/N) × |mean(p_i)-event_rate_i|`

例如两箱权重各 0.5，绝对校准差分别 0.02 和 0.06：

`0.5×0.02 + 0.5×0.06 = 0.04 ≤ 0.05`

但第二箱单独 0.06 超标，故总体通过不能掩盖最差分箱；发布规则同时检查 MCE 和临床关键分群。

## 安全后果

- 校准降低分数误导，但无法修复错误标签、样本选择偏差或数据漂移。
- 复杂校准器可能过拟合，必须时间外推和独立验证。
- 阈值层只能改变 Atlas 建议展示/阻断行为，不授予任何自动临床权限。
- 假阳性过高会增加告警疲劳；硬约束应优先保护患者安全，同时监控审核负担。

## 回滚方案

1. 新校准器异常时固定到上一签名版本；未校准的原始分数不得临时替代。
2. 新阈值导致队列超载时，优先提高提示/警示层的非临床操作成本或调整排班；不能跳过安全层。若确实需要变更阈值，必须重新走临床审批与独立验证。
3. 分群表现失效时对该分群 fail-closed，显示“当前评分不适用”，回退硬规则与人工审核。
4. 回滚验收包括旧版本可重现、ECE/灵敏度/假阳性率、阈值穿越矩阵、越界分数处理和 ADR-016 停用演练。
