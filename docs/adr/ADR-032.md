## 背景

附件要求自建至少 2,000 例回顾性评测集，含阴性对照，关键提醒召回不低于 95%、假阳性率不高于 5%、ECE 不高于 0.05。只报告点估计会让样本构成、病例难度、院区、标注一致性和数据泄漏不可见。相同患者进入训练、阈值选择和测试集，会使“准确率”虚高；直接复用生产数据还可能违反同意、最小必要和数据边界。

本 ADR 把评测集视为需要来源、版本、证据、访问和撤回规则的受监管产品，而不是散落在测试目录里的 JSON。平台只评测建议、告警和文书辅助能力，不做自主诊断、自动处方或替代医师。

## 选项对比

| 方案 | 可追溯/撤回 | 数据最小化 | 跨院区能力 | 结论 |
|---|---:|---:|---:|---|
| 工程师本机整理病例 | 低 | 未知 | 低 | 禁止生产发布依据 |
| 单个中央数据湖副本 | 中 | 较差 | 中 | 集中权限与出域风险高 |
| 联邦数据物理集中 | 高 | 差 | 高 | 原始数据长期集中，不采用 |
| 数据就地使用 + 不可变元数据/指标返回 | 高 | 好 | 中高 | **采用** |
| 只保存生产查询结果快照 | 低 | 差 | 低 | 易漂移且含真实标识，不采用 |

## 决策

### 1. 数据来源与合法性

- 数据仅来自经伦理/数据治理审批的回顾性来源，具有明确目的、访问范围、保留期和撤回机制。适用法律、知情同意豁免和地区要求为 `[待验证]`；验证方法是由每院区伦理、隐私负责人和法务书面确认来源与用途。
- 原始数据留在受控临床/评测环境；进入 Atlas 评测集前移除直接标识符，稀有组合按 ADR-012 做泛化、抑制和再识别评估。
- 临床评测数据不得进入压测、性能 fixture、演示环境或普通日志。此处允许的真实数据来源不授权 ADR-031 的压测例外。
- 每个病例登记来源机构、采集时间范围、纳排标准、许可依据、授权到期、临床负责人、访问组和撤回状态。
- 不得从生产结果中挑选“看起来好”的病例；纳排流程先冻结，病例流经队列和排除原因可审计。

### 2. 最小病例单元与泄漏隔离

拆分键优先使用患者主索引，而不是就诊或报告：

```text
同一患者的所有时间点、就诊和衍生文书只能进入一个 split
跨院区同一患者通过受控隐私匹配归为同一组
```

为降低时间泄漏，开发/阈值选择集早于测试集；外部测试来自不同时间段或不同院区。禁止相似文本复制、近重复检查失败、预处理统计跨 split 拟合。特征化、归一化、规则选择和阈值调参只能使用训练/开发集。

### 3. 标注治理

| 项目 | 规则 |
|---|---|
| 标注指南 | 定义正例、负例、模糊例、不适用和证据时间窗；版本化 |
| 双人标注 | 临床相关病例由两名独立合格标注者完成，初始看不到对方结果 |
| 分歧 | 第三方临床仲裁；保留原始判断和最终裁决 |
| 一致性 | 报告 Cohen's kappa 或适合分类的指标及置信区间，不仅报告百分比 |
| 证据 | 每标签绑定指南、检验值、时间点和资源引用；无证据标为不可判定 |
| 资格 | 标注者培训、考核、权限和持续一致性监测 |
| 污染隔离 | 标注者不能在没有记录的情况下修改已冻结测试标签 |

指南来源、标注者资格人数、每例时长和仲裁比例尚未由医院确定，均为 `[待验证]`。验证方法是小规模预标注、盲法重标和争议分析；冻结数据后进行随机 5% 双盲重标，低于预设一致性门槛则暂停发布并修订指南，而不是直接改标签。

### 4. 数据集注册与版本

每个版本 `EvalSet-vX.Y.Z` 包含不可变 manifest：

| 字段 | 内容 |
|---|---|
| 来源与许可 | 机构、项目号、目的、有效期、撤回状态 |
| 纳排 | 规则、排除数、缺失数据处理 |
| 病例 | 匿名病例 ID、split、场景、预期标签、证据引用 |
| 组成 | 阳性/阴性、科室、年龄组、院区、严重度、稀有病等 |
| 标注 | 指南、标注者资格、双标/仲裁、一致性 |
| 制品 | 特征/Schema/术语/规则/模型版本 |
| 完整性 | 文件清单、SM3 摘要、SM2 签名、生成时间 |
| 结果 | 指标、置信区间、亚组、失败案例引用、批准人 |

任何病例、标签、指南或拆分修改都生成新版本，禁止覆盖已用于发布决策的版本。访问清单最小化，离线审查使用受控执行而非批量下载。

### 5. 指标与门禁

| 指标 | 定义 | 发布门槛 |
|---|---|---|
| 关键提醒召回率 | TP / (TP+FN) | ≥95%，且报告下置信界与病例数 |
| 假阳性率 | FP / (FP+TN) | ≤5%，分母不能省略 |
| ECE | 各概率桶置信度与实际准确率差的加权和 | ≤0.05，桶策略固定 |
| 校准曲线 | 分桶及样本量 | 展示每桶 n，不只画平滑线 |
| 证据完整率 | 有有效具体证据的断言 / 全部断言 | 目标 100%；缺失按失败处理 |
| 结构合法率 | 通过 Schema/术语校验的比例 | 100% 才能写入候选草稿 |
| 亚组表现 | 按预先定义临床与部署切片 | 预先规定安全阈值和最小样本量 |

任何“准确率”必须同时报告数据集版本、病例构成、阳性/阴性分母、切分、置信区间、阴性对照、阈值和模型/提示/规则组合。不能从内部模型日志取得未校准分数后直接当临床概率。

数据源合法性、具体病种优先级、亚组阈值和最低亚组样本量均为 `[待验证]`。验证方法：按法规/伦理清单核验来源；用临床安全评审和历史事件制定阈值；按最大目标亚组计算样本量，并在真实标签冻结后用统计功效/区间宽度复核。

### 6. 发布、漂移与撤回

1. 新数据只进入候选版本；模型/阈值/提示变更在固定开发集调参后，只允许一次评估锁定测试集，防止反复窥视。
2. 门禁通过也不自动上线；需临床、安全、合规和数据所有者联合批准，生成签名评估报告。
3. 线上按 ADR-016 监控数据漂移、表现漂移、不良反馈、假阳性、证据缺失和关键亚组；达到强制停用阈值时停止新建议并转人工确定性路径。
4. 发现标签错误、来源失权、泄漏、严重病例遗漏或性能退化，立即冻结版本和派生物，通知所有使用方。
5. 撤回数据集不等同于删除不可篡改审计；评测明细按许可删除，受控审计仅保留版本、事件和决策证据。
6. 临床使用者可看到数据版本和批准范围，不可用旧评测集为新适应症背书。

## 可复算推导

### 2,000 例的点估计

若 2,000 个明确阳性病例中有 1,900 个真阳性：

```text
召回率 p̂ = TP/(TP+FN) = 1,900/2,000 = 95%
```

若另有 2,000 个明确阴性病例，其中 100 个假阳性：

```text
FP 率 = FP/(FP+TN) = 100/2,000 = 5%
```

2,000 是附件要求的总病例数，而上述计算需要知道阳性/阴性分母；不能把 2,000 同时当两类分母。该构成为示例且 `[待验证]`，必须由纳排后的数据清单给出真实 TP/FN/FP/TN。

### 召回率 Wilson 95% 区间

对 `n=2,000`、`x=1,900` 的二项比例，Wilson 区间中心近似：

```text
p̂=0.95，z=1.96
z²=3.8416
分母 = 1 + 3.8416/2,000 = 1.0009604
中心 = (0.95 + 3.8416/(2×2,000)) / 1.0009604
     ≈ 0.95005
半宽 = [1.96 × sqrt(0.95×0.05/2,000 + 3.8416/(4×2,000²))]
       / 1.0009604
     ≈ 0.00959
区间 ≈ [0.94046, 0.95964] = [94.05%, 95.96%]
```

若发布门槛要求“95% 召回率的下置信界也不低于 95%”，该样本点估计恰为 95% 并不能通过；应增加阳性病例或调整门槛。具体置信水平与统计规则为 `[待验证]`，由临床/统计负责人批准，计算使用冻结病例的真实分母。

### ECE

固定 B=10 个等宽概率桶：

```text
ECE = Σ(i=1..B) (n_i/N) × |acc_i - conf_i|
```

若 10 桶各 200 例、总体正确 1,900，则各桶平均准确率 `acc=0.95`。若每桶平均置信度分别给出，必须逐桶计算；例如 5 桶置信度 0.94、5 桶 0.96：

```text
ECE = (5/10)|0.94-0.95| + (5/10)|0.96-0.95|
    = 0.5×0.01 + 0.5×0.01
    = 0.01
```

例中 ECE=0.01，低于 0.05；这只说明该合成分桶，不能证明真实模型已校准。验证方法是在冻结测试集输出预测、标签和桶样本，固定插值/边界规则后计算 ECE、Bootstrap 区间与可靠性图。

### 数据拆分样例

2,000 例若按 70% 开发/调参、15% 内部验证、15% 锁定测试：

```text
开发 = 2,000×0.70 = 1,400
内部验证 = 2,000×0.15 = 300
锁定测试 = 2,000×0.15 = 300
```

按患者分组后可能无法恰好分配，最终数量以患者为整数单位调整，并报告实际值。比例不是医学证据充分性的证明；阳性、关键亚组和外部院区可能有更高样本要求，均为 `[待验证]`。

### 漂移触发预算

若测试集有 2,000 例、95% 召回的点估计，1 个真阳性变为假阴性：

```text
召回率 = 1,899/2,000 = 94.95%
相对点估计下降 = 0.05 个百分点
```

因此在线或周期漂移检测必须使用与发布一致的病例权重和置信规则，不能把“只少一例”视为无关紧要。实际强制停用阈值按临床风险设定，标为 `[待验证]`，由数据漂移监控与 ADR-016 联动测试。

## 安全后果

- 评测集集中可识别罕见患者；按患者/时间/机构分层、最小访问和再识别测试降低风险。
- 同一临床人员既标数据又批准模型会有职责冲突；数据治理、标注、评估和发布批准尽量分离并记录利益冲突。
- 高召回可能以假阳性为代价；必须联合看 FP、告警量、确认负担和临床后果，不允许只优化单一数字。
- 阴性对照选择不当会人为抬高或压低准确率；纳排指南、排除数与失败案例必须公开。
- 生产数据回归评测若未经批准同样越过数据边界；评测访问与 ADR-031 压测访问在网络和身份上隔离。
- 撤回后继续使用旧模型会失去依据；撤回事件必须驱动模型停用/回滚，而非只删除数据。

## 回滚方案

1. 数据集 manifest、模型、规则、提示和发布报告全部不可变并有签名，回滚单位是完整评估组合。
2. 发现泄漏、错误标签、来源问题或严重安全退化时立即冻结新建议生成；切回上一获批版本和确定性人工路径。
3. 已产生但未签核的候选草稿标记受影响范围并隔离；已签核内容由临床负责人启动更正/复核，不自动改写。
4. 撤回数据时停止访问并按许可删除评测副本，保留版本 ID、撤回原因、范围和签名审计。
5. 重新构建数据集必须生成新版本，从新冻结测试集一次性评估；不得在旧测试集上反复调参后宣称独立验证。
6. 恢复发布前须通过：泄漏扫描 0、来源有效、阴性对照齐全、Schema/术语 100%、召回/FP/ECE 及置信区间达标、临床联合批准。
