## 3. 核验流程

### 3.1 法规标准类

```
1. 找到官方正式发布渠道（政府网站、标准出版社）
2. 下载原文（PDF/Word）
3. 逐条核对文档中的引用
4. 标注差异（版本号、条文号、数值）
5. 更新文档或保留 [待验证]
6. 提交法务/合规组复核
```

### 3.2 临床阈值类

```
1. 组建临床治理委员会（3-5 名执业医师）
2. 提供评测数据集（合成 + 去标识化）
3. 回顾性评测（≥2000 例）
4. 统计置信区间和亚组差异
5. 委员会投票确定阈值
6. 签署批准文件
```

### 3.3 性能规模类

```
1. 搭建基准测试环境（至少 3 节点）
2. 使用合成数据（phi-scan 验证）
3. 执行压测剧本（MP-01~MP-08）
4. 记录硬件规格和原始结果
5. 给出算式和误差范围
6. 更新文档为 [已验证]
```

## 4. 优先级排序

### P0（必须在 P1 前完成）

- [ ] 等保三级控制项原文核对

- [ ] 药物相互作用规则库审核
- [ ] 剂量上限公式专家论证
- [ ] 急诊 RTO 临床需求确认

### P1（必须在 P3 前完成）

- [ ] EMPI 单实例容量基准
- [ ] FHIR 单实例 QPS 基准
- [ ] 关键提醒假阳性率评测
- [ ] 召回率评测
- [ ] ECE 校准曲线

### P2（可在 P5 后完成）

- [ ] 市场规模数字交叉验证
- [ ] 硬件采购成本询价
- [ ] 云服务 Spot 实例价格核对

## 5. 证据要求

每项核验必须提供：

1. **来源证明**: 原文链接、标准号、文号
2. **核对记录**: 差异说明、版本号
3. **责任人签字**: 合规组/临床组/法务组
4. **时间戳**: 核验日期
5. **复核机制**: 至少 2 人交叉核对
